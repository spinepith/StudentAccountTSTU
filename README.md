# ЛКС ТГТУ

</div>

Личный кабинет студента ТГТУ — это основной источник учебной информации. Однако пользоваться им через официальный сайт не всегда удобно: страницы могут долго загружаться, аутентификация периодически сбрасывается, а поиск нужных данных отнимает лишнее время.

ЛКС ТГТУ полностью решает данные проблемы. Это удобное решение, созданное специально для того, чтобы максимально упростить процесс получения важных учебных данных. Теперь всё самое необходимое всегда под рукой.

## Главные возможности
- Просматривать свои личные данные.
- Следить за баллами по дисциплинам.
- Узнавать расписание.
- Открывать зачетную книжку.
- Проверять свой рейтинг.

## Доступно везде
- Смартфоны: iOS и Android.
- Десктоп: Windows, macOS и Linux.
- Браузер: легковесная веб-версия, не требующая установки.
